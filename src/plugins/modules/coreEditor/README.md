# 正文编辑器

官方重型模块：章节正文编辑能力，冻结 `chapters/` 目录的 TipTap JSON 文档格式。

## 能力

- **章节正文**：全文编辑、撤销 / 重做（置左）、格式工具栏
- **导入 / 导出**：导出当前章节或全部章节为 TXT / Markdown / PDF（图片型，二级菜单）；导入 MD / TXT / PDF / Doc / Docx 到当前章节或作为新章节
- **富文本增强**：图片插入（可拖拽边缘调整大小）、表格插入与编辑、字体颜色（右键选中文本 → 更换颜色）
- **智能空格**：光标紧邻中文时输入全角空格，紧邻英文 / 数字时输入半角空格，中英混排更自然
- **工具栏定制**：插件配置中可逐项开关工具栏功能（文字 / 标题 / 列表 / 引用 / 代码块 / 撤销重做 / 图片 / 表格 / 导入导出）
- **大纲实例**：新工程默认带「大纲」编辑器实例（文件夹「大纲分卷」/ 文件「大纲」）
- **贡献点**：`editor.toolbar` / `editor.commands` / `editor.hoverActions` / `editor.blockTypes` / `i18n.resources` / `theme`

## 操作说明

### 章节与分卷（左侧章节栏）

- **新建**：标题行「新建分卷 / 新建章节」，或分卷行悬停按钮；列表原位输入命名，Enter 提交、Esc 取消（空名取消）
- **重命名 / 删除**：悬停章节或分卷行点铅笔 / 垃圾桶；删除需确认；删除分卷可选择「只删分卷（章节移至顶层）」或「连同全部章节删除」，删除不可撤销
- **排序**：按住拖动章节或分卷，出现朱砂插入细线时松开即落位（行间 = 插到该处；卷行高亮 = 拖入该卷）
- **视图切换**：章节栏可在「章节树 / 大纲」之间切换

### 正文编辑（工具栏）

- 撤销 / 重做（Ctrl/⌘+Z、Ctrl/⌘+Shift+Z）、加粗 / 斜体 / 删除线、标题 1 / 2 / 3、无序 / 有序列表、引用、代码块
- **字号**：工具栏右侧 A− / A+ 快速调节当前实例正文字号（也可在插件「配置」中设置，逐实例覆盖）
- **智能空格**：光标紧邻中文时自动输入全角空格，紧邻英文 / 数字时输入半角空格

### 右键菜单（按右键位置与选区不同，弹出不同菜单）

- **选中文字**：图标行加粗 / 斜体 / 删除线 / 清空格式 +「更换字体颜色」子面板（拖动取色实时预览、提交才写入；可清除颜色；记忆最近颜色）
- **光标在表格内**：最上方 / 最下方添加行、最左侧 / 最右侧添加列、删除表格
- **选中单元格**（蓝框选格）：加粗 / 斜体 / 删除线、清空所选内容、合并单元格、拆分单元格（不满足条件时灰置）、删除所选行 / 列、左右添加列、上下添加行
- **图片上**：删除图片、顺时针 / 逆时针旋转 90°（物理旋转：宽高属性随旋转互换，占位与拖拽手柄跟随旋转方向）

### 图片与表格

- **插入图片**：工具栏「插入图片」选图即插；选中图片后拖拽边缘（改单边）/ 角点（保持纵横比）缩放
- **插入表格**：工具栏「插入表格」选 3×3 或 5×3；行列增删、合并 / 拆分单元格、删除表格均通过右键菜单完成

### 导入 / 导出（工具栏「导入 / 导出」）

- **导入**：MD / TXT / PDF / Doc / Docx 可导入到当前章节（替换内容）或作为新章节（以文件名命名）
- **导出**：当前章节或全部章节导出为 TXT / Markdown / PDF（图片型，按应用内排版逐页截图嵌入 A4）；完成后窗口顶部提示导出路径，可一键「在文件夹中显示」

### 快捷键与配置

- 插件「配置」页：正文字号（可逐实例覆盖）、工具栏各组显示开关（文字 / 标题 / 列表 / 引用 / 代码块 / 撤销重做 / 图片 / 表格 / 导入导出）；编辑器快捷键改绑见同页「配置」tab

## 兼容性

- 文档格式与 `formatVersion` 绑定，跨版本稳定
- 编辑器快捷键作用域：`plugin:core.editor`（改绑见本插件「配置」tab）
- 导出的 PDF 为图片型：按应用内渲染效果逐页截图嵌入 A4 页（首页顶部保留小段边缘约 10mm），字体取系统已安装的中文字体
