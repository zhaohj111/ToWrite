# 正文编辑器

官方重型模块：章节正文的编辑中枢——沉浸写作、富文本编排、多格式导入导出一步到位。

## 设计目的

写作工具的核心不是排版，而是让思绪流畅落纸。编辑器模块围绕三点设计——

- **随手可写**：新建章节即成稿，正文即写即存，撤销重做常驻工具栏
- **够用的格式**：标题 / 列表 / 引用 / 字体颜色 / 表格 / 图片，不喧宾夺主；**智能空格**让中英混排自然
- **开合自如**：PDF / Markdown / TXT / Word / EPUB 随时导入导出，章节整体迁移无负担

## 能力

- **章节正文**：全文编辑、撤销 / 重做（置左）、格式工具栏
- **导入 / 导出**：当前章节或全部章节 → TXT / Markdown / PDF；MD / TXT / PDF / Word / EPUB 导入到当前章节或作为新章节
- **富文本增强**：图片插入（可拖拽边缘调整大小）、表格插入与编辑、字体颜色（右键选中文本 → 更换颜色）
- **智能空格**：光标紧邻中文时输入全角空格，紧邻英文 / 数字时输入半角空格，中英混排更自然
- **工具栏定制**：插件配置中可逐项开关工具栏功能（文字 / 标题 / 列表 / 引用 / 代码块 / 撤销重做 / 图片 / 表格 / 导入导出）
- **大纲实例**：新工程默认带「大纲」编辑器实例（文件夹「大纲分卷」/ 文件「大纲」）
- **贡献点**：`editor.toolbar` / `editor.commands` / `editor.hoverActions` / `editor.blockTypes` / `i18n.resources` / `theme`

## 数据

- 文档格式与 `formatVersion` 绑定，跨版本稳定；导出的 PDF 为图片型（按应用内排版逐页截图嵌入 A4）
