# 设置中心

应用核心模块：设置界面与级联配置体系的后端。不可禁用、不可实例化；在「已安装插件」页仅信息展示。设置页通过 `settings.pages` 贡献点注册，由设置视图统一渲染。

## 能力

- **设置目录树**：应用 / 插件 / 工程 / AI / 关于 五个分组，全局搜索
- **级联配置**：实例覆盖 > 应用级插件设置 > 出厂默认（manifest）
- **快捷键注册表**：应用级命令键位展示，插件作用域键位改绑与冲突检测
- **插件管理**：已安装插件、插件实例（双栏管理页）
- **贡献点**：`settings.pages`

## 兼容性

- 应用核心不可启停；AI 分组为 v0.7 占位
