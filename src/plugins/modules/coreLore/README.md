# 设定库

官方重型模块：人物 / 世界 / 势力等档案的集中管理。侧边栏为设定库文件树，主视图提供连接图与网格两种布局的卡片编辑区。

## 能力

- **文件树**：设定库条目按树状组织，随工程保存
- **双布局编辑区**：连接图（关系可视化）与网格卡片（批量编辑）
- **设定库导出**：导出 `.lore` 格式文件（在其它设备 / 工程间迁移设定），或导出 PNG 图片（连接图，按力导向布局绘制）
- **设定库导入**：读取 `towrite.lore` 文件，作为新文件加入当前设定库实例；文件内标签按名合并、卡片标签引用自动重映射
- **贡献点**：`sidebar.views`（设定库侧栏）

## 操作说明

### 设定库文件（左侧文件树）

- **新建**：标题行「新建分卷 / 新建设定库」，或分卷行悬停按钮；列表原位输入命名，Enter 提交、Esc 取消（空名取消）
- **重命名 / 删除**：悬停文件或分卷行点铅笔 / 垃圾桶；删除需确认；删除分卷可选择「只删分卷」或「连同全部设定库删除」，删除不可撤销
- **排序**：按住拖动文件或分卷，出现朱砂插入细线时松开即落位

### 卡片与关系（主视图）

- **双布局**：主区域工具栏可在「连接图 / 网格」间切换——连接图直观展示卡片关系连线，网格适合批量浏览与编辑
- **搜索与筛选**：顶部搜索框按设定名 / 内容过滤；标签筛选 chips 点击切换（标签多时可按住拖动横向滚动）
- **新建 / 编辑卡片**：新建卡片创建档案；点击卡片打开卡片编辑器（正文编辑、标签设置）；删除直接执行、可撤销（无需确认）
- **连接图操作**：拖拽卡片调整布局、滚轮缩放、平移画布、左下角控件放大 / 缩小 / 适应全部、右键进行连接/快速连接等
- **撤销 / 重做**：由主区域工具栏驱动（Ctrl/⌘+Z、Ctrl/⌘+Shift+Z）

### 导出 / 导入（右下角按钮）

- **导出**：`.lore` 格式文件（保留卡片、关系连线与实例标签，可跨设备与工程迁移）或 PNG 图片（连接图，需在「连接图」视图下导出；网格布局 / 搜索筛选时会引导切换）；完成后窗口顶部提示导出路径，可一键「在文件夹中显示」
- **导入**：读取 `towrite.lore` 文件，作为新文件加入当前实例；文件内标签按名合并、卡片标签引用自动重映射

## 兼容性

- 设定数据随 `.writeproj` 保存，与 `formatVersion` 绑定
- 导出的 `.lore` 文件为 JSON（含 `format: "towrite.lore"`、`version` 字段），可安全迁移
- 侧边栏变体挂载于活动栏「设定库」，可与其他模块实例并行使用
