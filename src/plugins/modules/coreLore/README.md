# 设定库

官方重型模块：人物 / 世界 / 势力等档案的集中管理，双视图编辑 + 与时间轴双向联动。

## 设计目的

设定是故事的骨架——设定库模块让收集与使用同样顺畅：

- **集中管理**：所有设定按文件树组织，人物、地点、物品随手可查
- **可视化关系**：连接图直观呈现设定间的关系网，网格视图适合批量整理
- **双向联动**：设定卡片关联时间轴标签，写正文时一念即达，改设定时时间线同步呈现

## 能力

- **文件树**：设定库条目按树状组织，随工程保存
- **双布局编辑区**：连接图（关系可视化）与网格卡片（批量编辑）
- **标签体系**：实例级标签分类 + 筛选搜索
- **时间轴联动**：设定卡片可关联时间轴文件，关联只按 id 保存，名称随文件树实时解析
- **导出 / 导入**：`.lore` 迁移格式 + 连接图 PNG 导出
- **贡献点**：`sidebar.views`（设定库侧栏）

## 数据

- 设定数据随 `.writeproj` 保存，与 `formatVersion` 绑定；导出的 `.lore` 文件为 JSON（含 `format: "towrite.lore"`、`version` 字段），可安全迁移
