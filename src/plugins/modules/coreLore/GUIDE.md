# 操作说明

## 设定库文件（左侧文件树）

- **新建**：标题行「新建分卷 / 新建设定库」，或分卷行悬停按钮；列表原位输入命名，Enter 提交、Esc 取消（空名取消）
- **重命名 / 删除**：悬停文件或分卷行点铅笔 / 垃圾桶；删除需确认；删除分卷可选择「只删分卷」或「连同全部设定库删除」，删除不可撤销
- **排序**：按住拖动文件或分卷，出现朱砂插入细线时松开即落位

## 卡片与关系（主视图）

- **双布局**：主区域工具栏可在「连接图 / 网格」间切换——连接图直观展示卡片关系连线，网格适合批量浏览与编辑
- **搜索与筛选**：顶部搜索框按设定名 / 内容过滤；标签筛选 chips 点击切换（标签多时可按住拖动横向滚动）
- **新建 / 编辑卡片**：新建卡片创建档案；点击卡片打开卡片编辑器（正文编辑、标签设置）；删除直接执行、可撤销（无需确认）
- **连接图操作**：拖拽卡片调整布局、滚轮缩放、平移画布、左下角控件放大 / 缩小 / 适应全部、右键进行连接/快速连接等
- **关联时间轴**：右键卡片菜单选择「关联时间轴」，或网格卡片右下角 Link2 按钮打开关联面板；点击面板内文件行添加关联，已关联列表可移除
- **编辑面板关联文件**：卡片编辑器中的「关联文件」行展示当前关联；点击「管理关联」可打开同一个关联面板，关联 chips 仅作展示，可按住左右拖动浏览
- **双向跳转**：点击关联 chips 可打开对应时间轴文件；在时间轴侧关联管理面板点击设定卡片可跳回本设定库并定位
- **撤销 / 重做**：由主区域工具栏驱动（Ctrl/⌘+Z、Ctrl/⌘+Shift+Z）

## 导出 / 导入（右下角按钮）

- **导出**：`.lore` 格式文件（保留卡片、关系连线、实例标签以及卡片关联的时间轴文件，可跨设备与工程迁移）或 PNG 图片（连接图，需在「连接图」视图下导出；网格布局 / 搜索筛选时会引导切换）；完成后窗口顶部提示导出路径，可一键「在文件夹中显示」
- **导入**：读取 `towrite.lore` 文件，作为新文件加入当前实例；文件内标签按名合并、卡片标签引用自动重映射；附带的关联时间轴 id 会逐条校验，不存在的引用会被丢弃并提示
