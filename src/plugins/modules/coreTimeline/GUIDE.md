# 操作说明

## 时间轴文件（左侧文件树）

- **新建**：标题行「新建分卷 / 新建时间轴」，或分卷行悬停按钮；列表原位输入命名，Enter 提交、Esc 取消（空名取消）
- **重命名 / 删除**：悬停文件或分卷行点铅笔 / 垃圾桶；删除需确认；删除分卷可选择「只删分卷」或「连同全部时间轴删除」，删除不可撤销
- **排序**：按住拖动文件或分卷，出现朱砂插入细线时松开即落位

## 画布与标签（主视图）

- **选中 / 编辑**：左键单击标签仅选中（虚线高亮）；左键双击标签就地编辑文字
- **移动**：左键拖标签移动；右键按住拖拽空白框选多个标签后，拖动任一选中标签整体移动
- **新建标签**：右键单击空白处，用工具栏「当前使用颜色」新建标签并就地输入文字
- **标签右键**：编辑文字 / 替换为当前颜色 / 替换颜色…（弹出取色面板，可应用到单个或多个选中标签）/ 删除
- **画布**：左键拖空白平移；滚轮以光标为中心缩放；左下角控件放大 / 缩小 / 适应全部；左上角显示当前视口的时间区间与刻度
- **撤销 / 重做**：Ctrl/⌘+Z、Ctrl/⌘+Shift+Z / Ctrl+Y（标签编辑输入框内由输入框自身处理）

## 设定库关联

- **关联管理**：工具栏「关联管理」打开悬浮面板，可添加 / 删除当前时间轴文件关联的设定卡片
- **关联 chips**：工具栏下方展示当前文件关联的设定卡片，点击 chip 跳转到设定库并定位对应卡片；chips 栏可按住左右拖动横向浏览

## 颜色图例（工具栏「颜色管理」）

- 悬浮面板按注释搜索、添加图例、修改图例注释、删除图例与批量删除
- 默认点选图例行即设为「当前使用颜色」（新建标签 / 替换颜色时使用）；替换标签颜色时，标签下方注释随图例一起更新
- 右上角图例最多展示 5 行，超出另起一列
- 点击右上角图例内容可快速隐藏/显示使用该图例的标签

## 导出 / 导入（右下角按钮）

- **导出**：`.timeline` 格式文件（保留节点 / 连线 / 时间坐标以及该文件关联的设定卡片，可跨设备与工程迁移）或高清 PNG 图片（按画布世界坐标绘制，图例中隐藏的颜色不会出现）；完成后窗口顶部提示导出路径，可一键「在文件夹中显示」
- **导入**：读取 `towrite.timeline` 文件，作为新文件加入当前实例，图例颜色自动合并；附带的关联设定卡片 id 会逐条校验，不存在的引用会被丢弃并提示
