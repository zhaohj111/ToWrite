# 时间轴

官方重型模块：按卷组织故事事件，在水平轴体上拖动事件标签，直观梳理剧情节拍。

## 能力

- **分卷 + 文件树**：事件按卷归档，随工程保存
- **水平轴体**：故事事件标签沿时间轴自由拖动定位
- **时间轴导出**：导出 `.timeline` 格式文件（在其它设备 / 工程间迁移时间轴），或导出高清 PNG 图片（画布内容按时间轴世界坐标绘制，图例中隐藏的颜色不会出现在图中）
- **时间轴导入**：读取 `towrite.timeline` 文件，作为新文件加入当前时间轴实例，图例颜色自动合并
- **贡献点**：`sidebar.views`（时间轴文件侧栏）

## 操作说明

### 时间轴文件（左侧文件树）

- **新建**：标题行「新建分卷 / 新建时间轴」，或分卷行悬停按钮；列表原位输入命名，Enter 提交、Esc 取消（空名取消）
- **重命名 / 删除**：悬停文件或分卷行点铅笔 / 垃圾桶；删除需确认；删除分卷可选择「只删分卷」或「连同全部时间轴删除」，删除不可撤销
- **排序**：按住拖动文件或分卷，出现朱砂插入细线时松开即落位

### 画布与标签（主视图）

- **选中 / 编辑**：左键单击标签仅选中（虚线高亮）；左键双击标签就地编辑文字
- **移动**：左键拖标签移动；右键按住拖拽空白框选多个标签后，拖动任一选中标签整体移动
- **新建标签**：右键单击空白处，用工具栏「当前使用颜色」新建标签并就地输入文字
- **标签右键**：编辑文字 / 替换为当前颜色 / 替换颜色…（弹出取色面板，可应用到单个或多个选中标签）/ 删除
- **画布**：左键拖空白平移；滚轮以光标为中心缩放；左下角控件放大 / 缩小 / 适应全部；左上角显示当前视口的时间区间与刻度
- **撤销 / 重做**：Ctrl/⌘+Z、Ctrl/⌘+Shift+Z / Ctrl+Y（标签编辑输入框内由输入框自身处理）

### 颜色图例（工具栏「颜色管理」）

- 悬浮面板按注释搜索、添加图例、修改图例注释、删除图例与批量删除
- 默认点选图例行即设为「当前使用颜色」（新建标签 / 替换颜色时使用）；替换标签颜色时，标签下方注释随图例一起更新
- 右上角图例最多展示 5 行，超出另起一列
- 点击右上角图例内容可快速隐藏/显示使用该图例的标签

### 导出 / 导入（右下角按钮）

- **导出**：`.timeline` 格式文件（保留节点 / 连线 / 时间坐标，可跨设备与工程迁移）或高清 PNG 图片（按画布世界坐标绘制，图例中隐藏的颜色不会出现）；完成后窗口顶部提示导出路径，可一键「在文件夹中显示」
- **导入**：读取 `towrite.timeline` 文件，作为新文件加入当前实例，图例颜色自动合并

## 兼容性

- 时间轴数据随 `.writeproj` 保存，与 `formatVersion` 绑定
- 导出的 `.timeline` 文件为 JSON（含 `format: "towrite.timeline"`、`version` 字段），可安全迁移
