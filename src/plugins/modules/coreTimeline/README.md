# 时间轴

官方重型模块：把故事事件按卷编排在水平轴体上，直观梳理剧情节拍与事件因果。

## 设计目的

写作中常常需要把时间线盘清楚：哪件事发生在什么时候、前因后果如何。时间轴模块围绕「一眼看清、随手调整」设计——

- 事件以**彩色标签**贴在水平时间轴上，颜色自带语义（图例注释），位置即时间
- 标签可与 **设定库卡片** 双向关联：人物 / 地点 / 物品的设定改动，时间线同步呈现
- 事件结构可整体**导出迁移**（`.timeline`），或渲染为高清 PNG 分享给编辑 / 读者

## 能力

- **分卷 + 文件树**：事件按卷归档，随工程保存
- **水平轴体**：故事事件标签沿时间轴自由拖动定位
- **颜色图例**：颜色与注释一对多，右上角随时查看 / 隐藏
- **设定库联动**：关联设定卡片，名称实时解析
- **导出 / 导入**：`.timeline` 迁移格式 + 高清 PNG 导出
- **贡献点**：`sidebar.views`（时间轴文件侧栏）

## 数据

- 时间轴数据随 `.writeproj` 保存，与 `formatVersion` 绑定，跨版本安全迁移
